# Architect

This context defines the recurring final-act challenge and the lineage it carries between completed runs.

## Language

**Architect Act**:
The mandatory fourth act presented to the player as **Act 4 — The Architect**, containing a fixed Rest Site, Shop, and Architect encounter.
_Avoid_: Bonus act, secret act

**First Visit**:
An Architect Act entered when no valid Challenger Snapshot exists for the active profile.
_Avoid_: First attempt, first run

**Repeat Visit**:
An Architect Act entered with a valid Challenger Snapshot, producing a continuous Corrupted Challenger-to-Architect encounter.
_Avoid_: Rematch, second visit

**Challenger Snapshot**:
The successor record of a completed Architect encounter: character identity, final deck and upgrades, and maximum health.
_Avoid_: Run save, checkpoint

**Architect Outcome**:
The mod-owned result of the Architect encounter, either Architect Win or Architect Loss, distinct from the base game's victory result for the completed run.
_Avoid_: Run result, Act 3 result
