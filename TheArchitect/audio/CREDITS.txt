Packaged file: heart_metal_cover.ogg, stereo Ogg Vorbis, 44,100 Hz.
Each new Architect fight starts at sample 0.
Loop start: sample 794,241, 0:18.01.
Loop end: sample 7,706,475 (exclusive), 2:54.75.
The file ends at the loop end; Godot's decoder repeats from the loop start.
The source file is unchanged. No fades or silence were added.

Re-encode from the supplied source with FFmpeg:
ffmpeg -i heart-metal-cover.m4a -map 0:a:0 -af "atrim=end_sample=7706475,asetpts=PTS-STARTPTS" -c:a libvorbis -q:a 6 -map_metadata -1 -metadata title="The Heart OST but it's Metal" -metadata artist=RYS heart_metal_cover.ogg

Corrupted Player excerpt: heart_metal_cover_corrupted.wav.
Stereo 16-bit PCM, 44,100 Hz, starting at source time 3:02.44.
The full source ending is retained, for a duration of about 37.755 seconds.
Relative loop start: sample 110,250, source time 3:04.94.
Relative loop end: sample 805,707 (exclusive), source time 3:20.71.
Godot loops those sample boundaries until victory, then disables looping and
continues from the current position to EOF. The ending never repeats.
WAV is used because its decoder supports disabling an interior loop without
discarding the audio after the loop end.

ffmpeg -i heart-metal-cover.m4a -map 0:a:0 -af "atrim=start=182.44,asetpts=PTS-STARTPTS" -c:a pcm_s16le -map_metadata -1 heart_metal_cover_corrupted.wav
